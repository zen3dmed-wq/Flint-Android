Flint 8.10.23 — добавление кнопки VPN на рабочий стол Android

Настройки → Добавить виджет на экран: окно с двумя способами добавления.
1. Виджет 1×1, меняющий цвет по состоянию VPN.
2. Обычная кнопка VPN размером с иконку приложения — запасной вариант
для оболочек, которые скрывают виджеты или игнорируют запрос добавления.
Ярлык имеет постоянную иконку; текущее состояние видно в уведомлении Flint.
Также: удерживать значок Flint → Вкл./выкл. VPN → перетащить на рабочий стол.
Подтверждение «Добавлено» показывается только после системного callback.
Есть подсказка ручного добавления и переход в настройки рабочего стола.
Виджету добавлено изображение предпросмотра для старых/OEM списков.
Установка только во внутреннюю память, как требуется приложениям с виджетами.
Нагрузка серверов считывается из актуального /api/v1/locations: load,
addresses и loadUpdatedAt. Разные узлы одной страны сопоставляются по адресу.
Ноль процентов отображается; null и устаревшие данные не подменяются нулём.
В автоматическом режиме нагрузка учитывается при выборе сервера.
Ручной выбор сервера сохраняется. Сайт не изменялся.

Установить APK поверх предыдущей версии и открыть Flint.
Подпись обновления сохраняется. Ничего удалять не нужно.
Совместимость с конкретной прошивкой OnePlus Ace 6T / ColorOS 16
нужно подтвердить на телефоне: это не результат физической проверки.
