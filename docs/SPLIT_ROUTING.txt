FLINT 8.10.12 — автоматическое раздельное проксирование

Назначение: российские сайты и обращения приложений к российским ресурсам
идут напрямую через интернет-провайдера, остальные назначения — через VPN.
Автоматический выбор основан на доменах и IP, а не на названии приложения.
Приложение с несколькими доменами может использовать оба маршрута.

В разделе «Сайты РФ» включите «Разделять трафик» и «Определять маршрут
автоматически». По умолчанию используются geosite category-ru, tld-ru,
geoip ru/private и сохранённые пользователем сайты. Локальная сеть доступна
напрямую. Список можно дополнить вручную. После изменения переподключите VPN.
При отключении автоматического режима остаются только пользовательские
исключения. При отключении разделения весь интернет-трафик идёт через VPN.

Правила применяются внутри Xray: домены распознаются по HTTP/TLS/QUIC,
IP-правила работают и без имени домена. Правила не меняют сервер в ручном
режиме выбора. Не совпавший с правилами трафик сохраняет маршрут через VPN.
В Android/iOS полный автоматический режим реализован для VLESS/Xray;
у других протоколов сохранено прежнее разделение по отдельным сайтам.
В Windows текущий движок — Xray. База поставляется вместе с приложением.

Существующее расширение routing.russianServices в GET /config может
заменить встроенные группы и добавить правила. Оно отдельно описано в
админке и НЕ входит в предоставленный Client API Swagger от 03.10.2026.
При отсутствии расширения работают встроенные правила. Обновление
приложения само по себе не развёртывает расширение на действующем сервере.

Проверка на Windows использует настоящий комплектный Xray с локальным
HTTP-прокси без TUN: домен .ru и локальный IP доступны при неработающем
VPN-выходе; при выключении разделения тот же запрос не проходит.
Это проверяет независимость прямого маршрута от VPN-сервера. Доступность
интернета у оператора и точность всех записей geosite/geoip не гарантируются.

Новый Client API: эталон docs/client-api.openapi.json сохранён без изменений.
Карточки тарифов учитывают savingsPercent/savings, traffic.limitBytes,
isPersonal, availableUntil. Просроченное предложение выбрать для оплаты
нельзя. Серверная нулевая скидка не заменяется расчётной.
Методы входа, подписок и заказов используют прежнюю базу /api/v1.
Расширения устройств, поддержки, маршрутов и загрузки VPS требуют серверной
интеграции; наличие сеанса входа не доказывает наличие отдельного VPN-ключа.
